# Assets do portfólio

Estrutura preparada para os materiais oficiais:

- `images/hero/`: imagem ou vídeo de abertura;
- `images/about/`: retrato e galeria de Henrique;
- `images/cases/`: capas e imagens dos cases;
- `images/brands/`: logos autorizados das marcas.

Ainda devem ser fornecidos: logotipo/assinatura, paleta, fonte, foto, mídia do hero, seis textos de atuação, método definitivo, três ou mais cases, manifesto, logos, depoimentos e todos os contatos e redes sociais.

Enquanto esses arquivos não existem, a aplicação usa formas abstratas em CSS e placeholders textuais para não gerar imagens quebradas nem representar pessoas ou marcas fictícias como reais.
